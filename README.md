# Herobrine Server

**Projeto acadêmico – Ciência da Computação**

## Sobre o projeto

O **Herobrine Server** é um projeto de montagem e personalização de um computador com temática inspirada no personagem Herobrine, do jogo Minecraft.

O projeto reúne conhecimentos de hardware, montagem de computadores, organização de componentes e personalização física. A estrutura foi desenvolvida utilizando MDF, com acabamento visual inspirado no universo do Minecraft, incluindo iluminação em LED e um botão personalizado com referência ao sistema de Redstone do jogo.

Além da parte estética, o computador foi montado com componentes reais e preparado para utilização em atividades de informática, testes e execução de sistemas virtualizados.

## Hardware utilizado

A configuração utilizada na montagem foi:

- **Processador:** Intel Core i3 de 3ª geração.
- **Placa-mãe:** H61.
- **Memória RAM:** 8 GB DDR3.
- **Armazenamento:** HD de 320 GB.
- **Fonte de alimentação:** 500 W.
- **Refrigeração:** Cooler para o processador.
- **BIOS:** Versão 1.

## Estrutura física

O gabinete foi construído em MDF, com dimensões aproximadas de 60 × 60 cm.

A personalização visual utiliza elementos característicos do Minecraft, buscando reproduzir a identidade do Herobrine. Entre os elementos implementados estão:

- Estrutura personalizada em MDF.
- Iluminação em LED.
- Botão inspirado no sistema de Redstone.
- Organização interna dos componentes.
- Sistema de ventilação para auxiliar na refrigeração.

## Software e utilização

O computador permite a instalação e execução de sistemas operacionais e ferramentas de informática.

Durante o desenvolvimento e os testes, foram consideradas tecnologias de virtualização, utilizando o VirtualBox para executar máquinas virtuais com distribuições Linux.

Também é possível acessar versões de Minecraft executadas diretamente pelo navegador, como Minecraft Classic e Eaglercraft, conforme a compatibilidade do ambiente.

## Objetivos do projeto

O desenvolvimento do Herobrine Server teve como principais objetivos:

- Aplicar conhecimentos de montagem e arquitetura de computadores.
- Identificar e compreender a função dos componentes de hardware.
- Desenvolver uma estrutura física personalizada para um computador.
- Trabalhar conceitos de refrigeração, alimentação e organização interna.
- Explorar a utilização de sistemas operacionais e virtualização.
- Integrar conhecimentos técnicos com criatividade e desenvolvimento prático.

## Resultado

O resultado é um computador funcional com estrutura personalizada, combinando montagem de hardware e identidade visual inspirada no Minecraft.

O projeto permitiu colocar em prática conhecimentos estudados durante a formação acadêmica, desde a identificação dos componentes até a montagem e organização de um equipamento completo.
